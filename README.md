# homework-weblayout-6.1
>Домашнее задание по курсу Веб-верстка, этап 6, задание 1
>(Whitemark, Вёрстка модального окна обратной связи)

[Макет в Фигме](https://www.figma.com/design/cn0fvIrhiky7qcJ0MIHWJP/Sminex-%D0%98%D0%9D%D0%A2%D0%95%D0%9A%D0%9E---%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D1%8B-Q2?node-id=0-1)

## Этапы работы над задачей

1. Откройте макет в Figma и экспортируйте изображения в выделенной области в необходимом формате
2. Сформируйте из скачанных иконок спрайт.
3. В файле проекта index.html найдите комментарий <!-- Модальное окно --> и для блока с классом *div class="modal"* добавьте модификатор modal--active, чтобы модальное окно появилось на странице браузера.
4. Внутри обёртки с классом <div class="modal__content"> создайте разметку заголовка и формы со всеми необходимыми атрибутами.
5. Сформируйте компонент custom-input для текстовых полей формы
6. На основе компонента custom-input подготовьте компонент custom-textarea 
7. Создайте компонент custom-checkbox
8. Укажите необходимый атрибут для обязательных полей — чекбокс, а также поле, помеченное * в макете.
9. Наполните форму обратной связи компонентами и сформируйте из них сетку, основываясь на дизайне из предоставленного макета в Figma
10. Сверстайте кнопку закрытия модального окна
11. Сверстайте спозиционированный относительно модального окна блок успешной отправки формы. Заложите ему изначально скрытое состояние и появление по модификатору --active
12. Сверстайте дополнительное состояние кнопки отправки формы

## Критерии оценки

1. При недостаточной высоте основного содержимого подвал страницы прижат к низу экрана
2. Поля формы находятся внутри тега form
3. У обязательных полей есть атрибут required.
4. Необходимо избегать избыточного увеличения веса селектора
5. Область взаимодействия с интерактивным элементом предсказуема и достаточна.
6. У интерактивных элементов при фокусе с клавиатуры есть визуальный отклик.
7. У спозиционированных графических элементов отключена кликабельность (pointer-events: none;)
8. Векторные изображения добавлены в спрайт.
9. У полей формы указаны атрибуты name и id, у радиокнопок указан value.
10. Вёрстка соответствует макету, учитывая проверку по Pixel Perfect (погрешность — 10 px).
11. Сетки разработаны с помощью технологии Flex или Grid.
12. У всех интерактивных элементов есть явная или скрытая текстовая подпись.
13. Добавлен скрытый заголовок при отсутствии подходящего заголовка из макета.
14. У кнопки верно заполнен обязательный атрибут type.
15. Основное содержимое страницы не должно находиться вне разделов. Весь контент внутри тега main должен располагаться в тегах section.
16. При формировании разделов горизонтальная центровка относительно краёв страницы должна выполняться за счёт утилитарного класса div class=”container”.
17. Соблюдена логика файловой структуры проекта.
18. Код отформатирован.
19. Вёрстка создана с помощью БЭМ.
20. Разметка сформирована согласно семантике.
21. Вёрстка прошла проверку на валидность.
22. При переносе из макета текст прошёл обработку типографом.
23. Графика выбрана в подходящем формате: JPG, PNG или SVG.
24. Всем ссылкам задано значение # для атрибута href.
25. Вёрстка проверена на переполнение контентом.
